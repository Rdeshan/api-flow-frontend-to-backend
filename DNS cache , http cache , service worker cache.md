D**caches use**

DNS cache 
HTTP cache
and Service Worker cache 

** purpose **

these are all mechanisms used to store data temporarily 

** Benefits **
to improve web performance, reduce latency, and decrease server load. They operate at different layers of the network and browser architecture and serve distinct purposes. 

*DNS Cache(Domain name system cache)*

**Purpose** - To speed up the domain name resolution process. Instead of performing a full DNS lookup every time a user visits a website, the device can quickly retrieve the IP address from its local cache, minimizing latency and network traffic.
